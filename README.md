# Dashboard Python — Ventes d'un supermarché

Tableau de bord interactif développé avec Python et Dash pour analyser les ventes d'un supermarché.

L'application permet notamment de visualiser :
- le montant total des ventes et le nombre d'achats ;
- la répartition des ventes par catégorie de produits ;
- l'évolution hebdomadaire des ventes ;
- les résultats selon la ville et le sexe des clients.

## Technologies

Python · pandas · Dash · Plotly

```bash
python app.py
```
